# Michael Soto — Portfolio

Personal portfolio website developed during my Full Stack Developer training.

The website presents my profile, skills, projects, CV, and contact information, with a focus on a clean and responsive user experience.

## Technologies

* HTML5
* SCSS / CSS3
* JavaScript
* Git & GitHub

## Features

* Responsive layout for desktop, tablet, and mobile
* Responsive navigation menu
* About Me section
* Projects section
* CV section with A4 print layout and PDF export
* Contact section
* Social and professional links

## Project Structure

The project is organized using HTML, SCSS, and JavaScript, with SCSS partials used to keep the styles modular and maintainable.
